# Changelog

All notable changes, additions, and bug fixes for the mod across Minecraft versions.

---

## Minecraft 1.6.4

### v1.8.6
* **Compatibility:** Updated to Minecraft 1.6.4.
* **Balance:** Nerfed Diablo and the Slaughter.

---

## Minecraft 1.6.2

### v1.8.5
* **Added:** Rare chance that hitting an IcePigman on "Hard" difficulty causes it to summon a thunderbolt with its Glowstone Sword.
* **Fixed:** Bug where IcePigmen were not holding Glowstone Swords.

### v1.8.4
* **Compatibility:** Updated to Minecraft 1.6.2.
* **Added:** Sound effects triggered on earning achievements.
* **World Gen:** Made Mazes rarer again.
* **Fixed:**
  * Achievement crash/tracking bug.
  * Spelling errors (e.g., `ignot` $\rightarrow$ `ingot`).
  * Minor miscellaneous bugs.

## Minecraft 1.5.2

### v1.8.2

## Minecraft 1.5.1

### v1.8 (Hotfix)
* **Configuration:** Renamed the config file to resolve crashes when running alongside the *More Health Enchanted* mod.
* **Configuration:** Added config options to prevent crashes related to achievements.

### v1.8
* **Compatibility:** Updated to Minecraft 1.5.1.
* **World / Save Migration:** Changed the dimension save folder. *(Note: If updating an existing `FallenSky` world, you must rename the save folder—see FAQ).*
* **Added:** Hell-Mushrooms can now be grown using bonemeal.
* **Changed:**
  * Reworked Giant Mushroom planting mechanics (Diablo).
  * Reduced Nether Armor protection values.
  * Updated crafting recipe for Nether Ingot.
  * Updated crafting recipe for Epic Nether Ingot.
  * Updated crafting recipe for Epic Nether Block.
* **Fixed:** Bug where the Plumbum Hammer was uncraftable.

* **Added:** Wall variants for each new fence type.

## Minecraft 1.4.2

### Mod 2.0
* **Added:** Dynamically generated Mazes in the Nether containing traps, chests, mob spawners, and more *(rarity configurable via config file)*.
* **Added:** Fake TNT for maze traps.
* **Added:** Nether Slime (functions similarly to lava; adds color variation to the Nether).
* **Added:** Nether Bucket (obtainable in dungeons only).
* **Changed / Balance:**
  * Completely overhauled Mud Lake generation.
  * Added a small cooldown to the Nether Bow.
  * Nether Bow now has a durability of 3,000 uses.
  * Very small chance for Nether Arrows to break on entity/block impact.
* **Removed:** Aeroclouds.
* **Fixed:**
  * Bug where the Glowstone Sword thunderbolt dealt no damage.
  * General bug fixes.

### Mod Version R1
* **Engine:** Migrated to Minecraft Forge.
* **Localization:** Added German language support.
* **Configuration:** Added block and item ID property configuration files.
* **Added:** Biome: **IceHell**.
* **Added:** Mobs: **IceGhost** and **IcePigman**.
* **Added:** Obsidian Slabs.
* **Added:** Giant Nether Mushrooms generating naturally in the Nether.
* **Added:** Bonemeal support to advance Nether Mushrooms to stage two.
* **Changed:** Updated spawn egg handling and recipes.
* **Changed:** Nether fences now properly connect to Nether Brick fence gates.
* **Fixed:** Spawn egg bugs.
